# Awesome Scripts 🚀

A comprehensive collection of automation scripts and agents designed to improve productivity and automate repetitive tasks.

## 📖 Documentation
Detailed information about the project structure and the list of available agents can be found in the [AGENTS.md](AGENTS.md) file.

## 🛠️ Project Structure
Each agent is contained within its own directory:
- `[agent-name]/`: Implementation files.
- `[agent-name]/agents.md`: Specific documentation for that agent.
